# Handoff workflow

This project is worked on across many short chats. `HANDOFF.md` carries context between them.

- **Start of every chat:** read `HANDOFF.md` first. Trust it; don't re-explore the codebase to rediscover what it already says.
- **End of every chat** (or when the user says "handoff"): update `HANDOFF.md` in place. Keep it under ~60 lines: overwrite stale info, don't append a history log. Git history is the log.
- Keep it factual and terse. File paths over prose.
